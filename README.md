# 📊 Cloth Store Analysis

## 📝 Project Overview
This project provides an in-depth analysis of a **Cloth Store dataset** using **Excel** to uncover valuable business insights. The dashboard presents key metrics, trends, and performance indicators to support data-driven decision-making.

## 📂 Dataset
**Download Dataset:** [Click here to download](https://github.com/shashwatvyass/Cloth-Store-Analysis/blob/main/Cloth%20Store%20Analysis.xlsx)

## 📈 Analysis & Insights
### ✅ Key Business Questions Answered:
- How do **sales and order trends** change over the months?
- What are the **top-performing sales channels**?
- Which **states generate the most revenue**?
- What is the **order status distribution** (Delivered, Cancelled, Refunded, etc.)?
- How does **gender and age** influence purchasing behavior?

## 📊 Dashboard Overview
### 🔹 Visuals Included:
- **Orders vs Sales** – Monthly sales trends
- **Orders by Channel** – Breakdown of sales channels (Amazon, Flipkart, Myntra, etc.)
- **Sales by Top 10 States** – Revenue contribution per region
- **Order Status** – Delivered, Cancelled, Refunded orders
- **Orders by Age & Gender** – Customer demographics
- **Sales by Men vs Women** – Gender-based sales contribution
